QUICK SETUP (5 STEPS)
================================================================================

STEP 1: Database Setup (15 min)
  1. Create Supabase project (https://supabase.com)
  2. Run supabase-schema.sql in SQL Editor
  3. Create 3 storage buckets

STEP 2: Stripe Setup (20 min)
  1. Create Stripe account (https://stripe.com)
  2. Create 4 pricing plans
  3. Add Webhook endpoint

STEP 3: Backend Deployment (30 min)
  1. Deploy stripe-webhook.js to Vercel/Netlify
  2. Set environment variables
  3. Update Stripe webhook URL

STEP 4: Frontend Integration (20 min)
  1. Add <script src="js/pap-backend.js"></script> to HTML
  2. Configure PAP_CONFIG with API keys
  3. Add function calls to pages

STEP 5: Testing & Deployment (25 min)
  1. Test all features locally
  2. Use Stripe test cards
  3. Deploy to production

Total Time: ~110 minutes (2 hours)

API REFERENCE (Quick Overview)
================================================================================

AUTHENTICATION
  papAuth.signUp(email, password, name)
  papAuth.signIn(email, password)
  papAuth.signInWithProvider('google' | 'apple')
  papAuth.signOut()
  papAuth.getUser()
  papAuth.isLoggedIn()
  papAuth.onAuthStateChange(callback)

PROFILE
  papUser.getProfile(userId?)
  papUser.updateProfile(data)
  papUser.getSubscription()
  papUser.uploadAvatar(file)

PAYMENT
  papPayment.createCheckout(planId, billingCycle)
  papPayment.redirectToCheckout(planId, billingCycle)
  papPayment.cancelSubscription()

SUBMISSION
  papSubmit.submitEditorial(formData)
  papSubmit.submitPullLetter(formData)
  papSubmit.uploadFile(file, bucket)
  papSubmit.uploadFiles(files, bucket)
