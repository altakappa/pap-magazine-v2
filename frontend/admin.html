메뉴 카테고리 관리

햄버거 메뉴(≡)를 눌렀을 때 우측 컬럼에 표시되는 카테고리 목록을 관리합니다.

✏️ 인라인 편집: 각 셀을 직접 클릭해서 수정 → 값이 바뀌면 💾 저장 버튼이 활성화됩니다 → 저장 시 해당 행만 업데이트.
↺ 되돌리기: 저장 전이라면 ↺ 버튼으로 원래 값으로 복원 가능.
➕ 새 메뉴: 표 맨 아래 초록색 하이라이트 행에서 라벨/URL 입력 후 ➕ 추가. 팝업 없이 바로 등록.
동작: 저장 시 즉시 웹사이트 전체 페이지의 햄버거 메뉴에 반영됩니다 (edge cache 최대 1분).
링크 유형: /community (정적 페이지), /#all-editorials (홈페이지 오버레이), https://... (외부 URL) 모두 가능.
스타일: default(흰) · red(빨강 강조) · gold(매거진 골드) · muted(회색). 다국어 라벨을 원하면 i18n 키(navEditorial 등)를 입력.
