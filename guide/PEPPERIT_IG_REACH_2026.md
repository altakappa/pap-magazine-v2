## 확산 규칙 (모든 게시물·릴스에 적용)

### 1. 해시태그 — 정확히 5개, 캡션 맨 아래, 줄바꿈 구분
2025년 12월부터 캡션+댓글 합산 최대 5개 제한. 댓글 해시태그는 스팸
분류 위험이 있으므로 반드시 캡션에 넣는다. 조합 공식:

- **팬덤 태그 2개**: 아티스트 한글명 + 영문명 또는 그룹명
  (예: #제니 #JENNIE / #투애니원 #2NE1)
- **콘텐츠 니치 태그 1개**: 이 게시물 주제를 팬이 검색할 말
  (예: #무대의상 #공항패션 #케이팝추억 #아이돌데일리룩)
- **카테고리 태그 1개**: 페퍼릿 카테고리 연동
  (NEWS→#케이팝뉴스, LOOK→#아이돌패션, MOMENT→#케이팝모먼트 등)
- **브랜드 태그 1개**: #페퍼릿 고정
- 매 게시물 조합을 새로 짠다. 동일 세트 반복 금지.

예시 (제니 무대의상 게시물):
```
#제니
#JENNIE
#무대의상
#아이돌패션
#페퍼릿
```

### 2. 셀럽 계정 @태그 — 본문 언급 + 게시물 태그 둘 다
본문에 @핸들을 쓰는 것(현재도 함)에 더해, 이미지에 계정 태그를 걸면
해당 셀럽의 "태그됨" 탭에 노출된다. 팬덤이 태그됨 탭을 정주행하는
문화가 있어서 무료 노출 지면이다.

### 3. DM 공유 설계 — "최애가 같은 친구에게 보내는 장면"
페퍼릿의 공유 단위는 팬덤이다. 훅과 마지막 문장이 "OO 팬인 친구에게
이거 보내야지"가 되는 각도인지 확인한다. 직접적인 "공유해줘"는 금지
(현재도 안 함 — 유지).

### 4. 저장 설계 — 정보 밀도
무대의상 브랜드명·스타일리스트·발매일·컴백 일정처럼 "나중에 다시
찾아볼 정보"를 본문에 명확히 남긴다 (제니 의상 게시물의 브랜드 크레딧
방식이 정답 — 전 게시물로 표준화).

### 5. 릴스 우선 + 커버 텍스트
비팔로워 도달은 릴스가 가장 넓다. 추억 소환·무대 클립형 콘텐츠는
릴스로. 커버 이미지에 큰 한글 텍스트(예: "14년 전 오늘, 2NE1")를
넣으면 프로필 그리드와 탐색탭에서 스크롤 스토퍼가 된다.

### 6. 게시 시간 — 팬덤 활동 시간
Z세대 케이팝 팬 기준: 평일 하교·퇴근 후 17~19시, 밤 22~24시가
피크. 뉴스성은 속보 즉시, 기획성(추억·룩)은 위 시간대에.

### 7. 유지할 것 (바꾸지 말 것)
- 한국어 훅 첫 줄 (이미 우수)
- "Let's Pepperit. 🩷" 클로징 시그니처
- 에디터 셀프 첫 댓글 (참여 신호 부스터)
- 반말 섞인 에디터 톤

## 계정 레벨 액션 (1회성)

1. 프로필 링크가 bit.ly 미디어킷 하나뿐 → pepperitmag.com(웹 허브)으로
   교체하거나 링크 2개 등록 (인스타는 링크 5개까지 지원). 웹 허브에는
   이미 팔로우 깔때기가 구축돼 있음.
2. 고정 게시물 3개 지정: 가장 반응 좋았던 게시물 + 페퍼릿 소개 +
   최신 화제작. 프로필 방문→팔로우 전환률을 올리는 기본기.
3. 최근 게시물 3~5건에 위 공식으로 해시태그 5개 추가 (게시물 수정).
