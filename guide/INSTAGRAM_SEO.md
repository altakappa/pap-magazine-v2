# PAP MAGAZINE — 인스타그램 SEO 플레이북 (@pap_magazine)

> 2026-07-04 작성. 목표: 인스타그램 내부 검색 + 구글 검색 양쪽에서 @pap_magazine 노출 극대화.
> 배경: 2025년 7월 10일부터 인스타그램은 **프로페셔널 계정의 공개 게시물을 구글이 색인**하도록 허용했다.
> 캡션·alt text·바이오가 이제 구글 검색결과의 제목/스니펫 역할을 한다. 즉, 게시물 하나하나가 웹페이지처럼 작동한다.

## 0. 선행 조건 체크 (5분, 1회)

| 항목 | 확인 방법 | 상태 |
|---|---|---|
| 프로페셔널(비즈니스/크리에이터) 계정 | 설정 → 계정 유형 | 확인 필요 |
| 공개 계정 | 설정 → 계정 공개 범위 | 확인 필요 |
| **검색엔진 색인 허용** | 설정 → 계정 공개 범위(Account Privacy) → "검색 엔진이 회원님의 콘텐츠를 표시하도록 허용" **켜기** | ★ 가장 중요 — 18세 이상 프로 계정은 기본 ON이지만 반드시 직접 확인 |
| 웹사이트 필드 | 프로필 편집 → 웹사이트: `https://www.pap-magazine.com` | 확인 필요 |

서브 계정(pap_korea, papceleb_, papfashion_, papbeauty_, pap_trends, papstudios_, pap_object)도 동일하게 적용.

## 1. 프로필 최적화 (10분, 1회)

인스타 검색은 **username + 이름 필드**를 가장 강하게 본다. 이름 필드는 username과 겹치지 않는 검색 키워드로 채운다.

- **이름 필드(Name)**: `PAP MAGAZINE | Fashion Editorial & Culture` (30자 제한 내)
  - 한글 검색 대응이 필요하면 `PAP 매거진 | Fashion Editorial` 형태도 가능. "팝매거진"으로 검색되길 원하면 이름 필드에 포함하는 것이 유일한 방법.
- **바이오 첫 줄에 핵심 키워드**: 예)
  `Global fashion editorial magazine — 매월 20+ 에디토리얼`
  `Fashion · Beauty · Culture · Film`
  `Seoul → Worldwide. Submissions open`
- **카테고리 라벨**: "잡지/미디어" (Magazine) 설정.
- **링크**: 웹사이트 링크는 항상 `www.pap-magazine.com` 고정 (링크트리류 외부 서비스보다 자체 도메인이 SEO 신호가 더 좋다). 다중 링크가 필요하면 인스타 자체의 "링크 추가" 기능으로 `/subscribe.html`, `/archive` 추가.
- 서브 계정 바이오에는 반드시 메인 `@pap_magazine` 멘션 → 계정 네트워크가 하나의 브랜드로 묶임 (웹사이트 sameAs 스키마와 일치).

## 2. 게시물 캡션 공식 (매 게시물)

구글은 **캡션 첫 125자를 검색 스니펫으로** 쓴다. 첫 줄이 곧 제목이다.

```
[키워드가 담긴 첫 줄 — 125자 내, 한/영 병기]
PAP EDITORIAL — "TITLE" by Photographer Name | Seoul fashion editorial

[본문 — 기존 PAP 캡션 스타일 유지 (KO/EN/IT)]

[크레딧 — @태그. 태그된 계정의 검색 가중치 공유]

[해시태그 3~5개만 — 아래 §4]
```

원칙:
- 첫 줄에 "fashion editorial", "beauty", 아티스트명, 브랜드명 등 **사람들이 실제 검색할 단어**를 자연스럽게 배치. 키워드 나열은 스팸으로 감지되어 역효과.
- 에디토리얼 제목이 추상적이면 첫 줄에 설명어를 붙인다: `"NOCTURNE" — a Milan-based beauty editorial for PAP Magazine`.
- 웹사이트에 올라간 콘텐츠라면 캡션에 `Full story → link in bio` + 사이트의 해당 기사에는 인스타 게시물 링크(이미 admin의 source_instagram_url 필드 활용) — 양방향 신호.

## 3. Alt Text — 가장 저평가된 무기 (매 게시물, 장당 10초)

게시물 업로드 → 고급 설정 → **대체 텍스트 작성**. 구글 이미지 검색과 인스타 검색 둘 다 읽는다.

- 공식: `[아티스트/브랜드] [의상·뷰티 디테일] [무드] — PAP Magazine fashion editorial`
- 예: `Model in oversized black Balenciaga coat, wet-hair beauty look, shot on film — PAP Magazine editorial`
- 캐러셀이면 각 장마다 다르게. 기존 게시물도 수정 가능(게시물 편집 → 대체 텍스트).

## 4. 해시태그 — 2026년 기준

해시태그의 발견 가중치는 줄고 **캡션 키워드가 우선**이다. 30개 나열은 역효과.

- **3~5개만**: 콘텐츠 분류용 1~2개(#fashioneditorial #beautyeditorial) + 니치 1~2개(#filmphotography #koreanfashion) + 브랜드 태그 1개(#papmagazine)
- 모든 게시물에 `#papmagazine` 고정 → 브랜드 태그 아카이브 형성.

## 5. 릴스 & 검색 상위 노출

- 릴스에도 같은 캡션 공식 적용. **영상 위 텍스트 오버레이**도 검색 색인 대상 — 첫 3초 화면에 제목/키워드 텍스트.
- 커버 이미지에 제목 텍스트 → 프로필 그리드와 검색 결과에서 가독성.
- 필름(영상 에디토리얼)은 유튜브 + 릴스 동시 배포, 캡션에 동일 제목 사용 → 구글이 같은 작품으로 클러스터링.

## 6. 웹사이트 ↔ 인스타그램 크로스링크 (구현 완료 ✅)

| 항목 | 상태 |
|---|---|
| 홈 Organization 스키마 `sameAs` (IG 8계정 + FB/YT/Threads) | ✅ 기존 구현 |
| **모든 SSR 상세페이지 publisher에 `@id` + `sameAs`** | ✅ 이번에 구현 (`api/_lib/seoRenderer.js`) |
| 푸터 INSTAGRAM 링크 | ✅ 기존 구현 |
| 기사 ↔ 원본 IG 게시물 연결 (`source_instagram_url`) | ✅ 기존 구현 |

효과: 구글 지식그래프가 `pap-magazine.com`과 `@pap_magazine`을 동일 브랜드로 인식 → 브랜드 검색 시 사이트와 IG가 함께 노출되고 상호 랭킹 신호 공유.

## 7. 운영 루틴

**매 게시물 (기존 워크플로 +2분):** 첫 125자 키워드 첫 줄 → alt text 전 장 입력 → 해시태그 3~5개 → 크레딧 @태그.

**월 1회 (10분):**
- 인스타 프로페셔널 대시보드에서 "프로필 활동 → 검색으로 유입" 추이 확인.
- 구글에서 `site:instagram.com/pap_magazine` 검색 → 색인된 게시물 수 증가 확인.
- 잘 검색되는 게시물의 첫 줄 패턴을 다음 달에 복제.

**기존 게시물 소급 (선택, 주 10개씩):** 조회수 상위 게시물부터 alt text와 첫 줄만 수정. 2020-01-01 이후 게시물이 색인 대상이므로 아카이브 전체가 잠재 검색 자산.

## 8. PAP만의 강점 활용

- **바이링구얼 캡션(KO/EN/IT)** = 3개 언어 검색 시장 동시 커버. 첫 줄은 영어(글로벌 검색량 최대), 둘째 줄 한국어.
- **크레딧 태그 문화**: 포토그래퍼/스타일리스트 계정 태그는 그들의 팔로워 검색 그래프에 PAP를 연결하는 백링크와 같다. 지금처럼 전 크레딧 태그 유지.
- **8계정 허브-스포크**: 서브 계정 게시물 캡션에 `Editorial via @pap_magazine` 한 줄 → 메인 계정으로 권위 집중.
