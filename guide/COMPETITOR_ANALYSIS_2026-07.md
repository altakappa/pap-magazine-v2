## 2. 핵심 발견

1. **볼륨 게임**: 빅3는 하루 27~30편 뉴스 와이어 모델 (참여율 0.12~0.2%로 낮음).
   PAP은 하루 3.6편 — 아이즈의 1/8. 도달 총량 격차의 근본 원인.
2. **벤치마크 = HIP**: 하루 17편 + 참여율 0.915%. "한 줄 제목 + 위트 + 속보성" 캡션.
   PAP 참여율(0.35%)은 빅3의 2~3배 → 체질은 좋고 볼륨만 부족.
3. **PAP 숨은 강점 = 댓글 밀도**: 팔로워 대비 댓글 최상위권. 팬덤 콘텐츠(뷔 248개,
   정국 169개)에서 폭발. 댓글은 2026 알고리즘에서 최강 신호.
4. **시간대 갭**: 경쟁 5사 전부 오전 8~11시(출근길) 집중. PAP은 21시 몰빵(30편 중 7편).
   오전 슬롯은 수요 검증된 무주공산.
5. **콘텐츠 갭 = 스포츠×컬쳐**: 아이즈·HIP·데패뉴 최고 성과 게시물이 전부 축구
   (월드컵 8강·이강인·호날두·벤투). 월드컵 특수를 경쟁사만 흡수 중.
6. **구조적 우위 = 웹 검색**: 경쟁 5사는 전부 인스타 중심, 웹 SEO 부재.
   PAP만 기사가 구글 뉴스·네이버·빙에 실시간 색인됨 → 그들이 인스타에서 터뜨린
   토픽의 "검색 지면"은 우리가 차지할 수 있다.

## 3. 선점 실행 계획

### 자동화 (구축 완료)
- **경쟁사 감시 크론** `/api/cron/competitor-watch` — 매일 07:50 KST에 경쟁 5사의
  지난 24~36시간 게시물을 스캔, 팔로워 보정 점수로 뜨는 토픽 추출, 우리 최근 기사와
  대조해 "오늘 선점할 기사 3~6개 + PAP 각도 + 검색 키워드"를 생성 → trend_reports 저장.
- 기존 파이프라인과 결합: 선점 기사를 웹에 발행하는 순간 IndexNow·WebSub 실시간 핑
  + X 자동 트윗 → 경쟁사가 웹에 없는 동안 검색 결과 선점.
- 수동 확인: 관리자 토큰으로 `GET /api/cron/competitor-watch?dry=1`

### 운영 (사람이 하는 것)
1. **게시량 증대**: 하루 3.6 → 6~8편. 단 연속 게시 금지(도달 분산 실측) —
   오전 8~11시 / 12시 / 18시 / 21시 슬롯 분산.
2. **오전 슬롯 신설**: 경쟁사 검증 완료 시간대. 선점 브리핑(07:50 도착)을 보고
   오전 중 1~2편 대응 발행이 이상적 사이클.
3. **댓글 증폭**: 캡션 끝에 질문·양자택일 유도 문구. PAP의 구조적 강점 극대화.
4. **월드컵 시즌 코너**: 축구선수 착장·스타디움 패션·유니폼 컬래버 등
   PAP다운 각도의 스포츠×패션. (섹션 고정이 아니라 시즌 한정 실험)
5. **브랜디드 콘텐츠 자신감**: 패페 1위 게시물이 #협찬 (메타윈×시세이도).
   협찬 표기가 도달에 불이익 없음이 경쟁 데이터로 검증됨 — 광고 영업에 활용.
