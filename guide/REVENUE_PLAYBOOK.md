# 1축 — B2B: 브랜드가 지불

## 1-1. 스폰서드 에디토리얼 (플래그십 상품)

**개념** — 브랜드의 제품·컬렉션을 PAP의 미학으로 녹인 화보를 제작해 IG 게재 + 웹 영구 아카이브 + 브랜드 허브 등재까지 패키지로 판매. 매거진 수익모델의 왕도이며, PAP의 아트 기반 톤이 곧 프리미엄 근거다.

**PAP 적용** — 이미 가진 것으로 완성되는 상품:
- 전 세계 크리에이티브 팀 네트워크 → 외주 스튜디오 대비 제작원가 우위
- 크레딧 시스템 → 브랜드가 "Fashion by @브랜드"로 자연 노출된 이력 92편
- /brand/:id 페이지 → "게재되면 이런 전용 페이지가 생깁니다" 시연 가능
- 새 캡션 시스템(한국어 훅) → 도달 성과 근거 제시 가능

**가격 감각** — 국내 디지털 매거진 스폰서드 화보: 소형 매체 100만~300만, 중형 300만~800만, 보그·엘르급 수천만. PAP 포지션(37만 팔로워, 아트 크레딧): **시작 라인업 제안**
- BASIC (게재형): 브랜드 제공 화보를 PAP 큐레이션으로 게재 + 허브 등재 — 80만~150만
- STANDARD (제작형): PAP 크리에이티브 팀이 화보 제작 + IG 2게시물 + 웹 아카이브 — 250만~500만
- PREMIUM (캠페인형): 제작 + IG 시리즈 3회 + 릴스 + 뉴스레터 + 허브 상단 고정 3개월 — 600만~1,200만

**실행 단계**
1. 미디어킷에 위 3패키지·가격·프로세스(문의→컨셉→제작 3주→게재) 명시
2. editorial_brands DB에서 기존 등장 브랜드 추출 → "귀사가 등장한 화보 + 브랜드 페이지" 링크를 담은 아웃바운드 이메일 (contact@pap-magazine.com 발신)
3. 국내 신진 디자이너·뷰티 브랜드부터 (의사결정 빠름) → 레퍼런스 2건 확보 → 단가 인상
4. 계약서 템플릿: 사용권 범위(브랜드 2차 사용 시 라이선스 별도 = 4-1 연결), 크레딧 표기, #AD 표기

**리스크·주의** — 편집권 침해 요구(브랜드가 화보 톤까지 지시)는 거절 기준 명문화. 광고 표기 누락은 표시광고법 위반 + 신뢰 훼손.

## 1-2. 스폰서드 기사·뉴스

**개념** — 신제품 출시·컬렉션·팝업·이벤트를 PAP 기사 형식으로 작성해 IG+웹 게재. 화보보다 제작 부담이 낮아 회전율 높은 "볼륨 상품".

**PAP 적용** — pap-article 스킬(바이링구얼 기사) + 새 확산 캡션 시스템이 그대로 제작 라인. 기사 1건 제작 시간이 짧아 월 4~8건 소화 가능.

**가격 감각** — 건당 30만~150만원 (IG 게재 포함 여부, 웹 아카이브 기간에 따라). 월 4건×70만 = 280만원의 안정 매출 축.

**실행 단계**
1. 미디어킷에 "뉴스 게재" 상품 추가 (화보 대비 진입가 낮은 첫 거래 상품으로 포지셔닝)
2. 팝업·행사 시즌(패션위크 전후) 홍보대행사 대상 아웃바운드 — 대행사는 반복 발주처
3. 어드민 기사 시스템에 sponsored 표기 필드 추가(웹·캡션 자동 #AD) — 개발 1시간짜리, 요청 시 구현

**리스크** — 스폰서드 비중이 피드의 20%를 넘으면 팔로워 이탈 신호 — 월 상한을 정해둘 것.

## 1-3. 브랜드 허브 유료 등급 (B2B 구독 = MRR)

**개념** — 이미 구축된 /partners·/brand/:id·배지를 무료(크레딧 기반)과 유료 파트너 등급으로 계층화. 매거진의 "지면 판매"를 구독형으로 바꾼 상품 — 한 번 팔면 매달 들어온다.

**PAP 적용** — 페이지·배지·SEO(브랜드 사이트맵)가 전부 배포 완료 상태. 유료 혜택만 정의하면 됨:
- 허브 상단 PARTNER 섹션 고정 노출
- 브랜드 페이지 커스텀(로고·소개문·외부 링크·룩북 섹션)
- "AS FEATURED IN PAP" 배지 공식 사용권 + 인증 링크
- 월간 노출 리포트(브랜드 페이지 조회·에디토리얼 노출)

**가격 감각** — 월 10만~30만원. 20개 브랜드 확보 시 MRR 200만~600만원.

**실행 단계**
1. brands 테이블에 tier 컬럼 활용(이미 존재) → paid 티어 추가
2. Paddle/PortOne 정기결제 상품 등록 (인프라 완비)
3. 스폰서드 에디토리얼 고객에게 후속 업셀 ("게재는 끝났지만 페이지는 계속 삽니다")

**리스크** — 유료 등급이 편집 크레딧과 혼동되지 않게 PARTNER 라벨 명확화.

## 1-4. 인스타그램 브랜디드 콘텐츠 / 파트너십 광고

**개념** — PAP이 만든 게시물을 브랜드가 자기 광고 계정으로 증폭(파트너십 광고). 콘텐츠 제작비 + 광고 권한 사용료를 받는다. 브랜드 입장에선 "매거진이 만든 네이티브 소재"가 자체 광고보다 성과가 좋아 수요가 꾸준하다.

**가격 감각** — 게시물 제작 50만~150만 + 광고 권한(30~90일) 30만~100만.

**실행 단계** — IG 크리에이터 도구에서 브랜디드 콘텐츠 설정 → 미디어킷에 "Paid Partnership 상품" 명시. 스폰서드 화보/기사에 옵션으로 끼워 파는 게 가장 쉽다.

## 1-5. 뉴스레터 스폰서십

**개념** — 정기 뉴스레터의 상단/중간 스폰서 슬롯 판매. 이메일은 도달률이 알고리즘에 좌우되지 않는 유일한 채널이라 광고 단가가 안정적.

**PAP 적용** — email_campaigns 시스템 구축 완료, 그러나 최근 30일 발송 0 (growth-audit이 감시 중). **선행 조건: 주 1회 발행 습관 + 구독자 확대** (548명 가입자를 뉴스레터 수신 동의로 전환하는 것부터).

**가격 감각** — 국내 뉴스레터 광고 시세 대략 구독자 1천 명당 3만~10만원/회. 5천 구독자 도달 시 회당 15만~50만.

**실행 단계** — ① 주간 큐레이션 레터 포맷 확정(에디토리얼 3편+뉴스) ② 3개월 발행 실적 쌓기 ③ 오픈율 데이터로 스폰서 영업.

## 1-6. 제작 스튜디오 (서비스 매출)

**개념** — 매거진 게재 없이, 브랜드 자체 채널용 화보·영상을 제작 대행. 미디어가 아니라 에이전시로서의 매출 — 매거진 신뢰도가 영업 자산이 된다.

**PAP 적용** — papstudios_ 핸들 보유. 크리에이티브 팀 네트워크가 밀라노·서울에 걸쳐 있어 로케이션 제작 경쟁력. 서브미션으로 검증된 팀에게 일감을 주는 구조 = 커뮤니티 선순환(크리에이터 수익 → creator_earnings 테이블로 정산).

**가격 감각** — 룩북/화보 1회 촬영 패키지 300만~1,000만 (팀 구성·컷수에 따라). 마진 30~50%.

**실행 단계** — papstudios 포트폴리오 페이지(기존 에디토리얼 중 제작 사례 큐레이션) → 미디어킷 별첨 → 스폰서드 문의 중 "자체 채널용" 수요를 스튜디오로 라우팅.

## 1-7. 이벤트/취재 패키지

**개념** — 브랜드 행사(팝업·쇼·파티)의 공식 미디어 파트너로 들어가 취재+화보+게시 패키지 판매.

**가격 감각** — 국내 행사 취재 패키지 100만~400만, 해외(밀라노 등) 현지 팀 활용 시 300만~800만.

**실행 단계** — 시즌 캘린더(서울·밀라노 패션위크, 브랜드 팝업 시즌) 기준 2개월 전 아웃바운드.

# 2축 — B2C: 독자·크리에이터가 지불

## 2-1. 멤버십 구독 재설계

**개념** — 콘텐츠 접근·경험·소속감을 파는 정기결제. 현재 1명(₩8,500 MRR)인 이유는 기능 부재가 아니라 **가치 제안 부재** — "구독하면 뭐가 달라지는가"에 답이 없다.

**PAP 적용 — 재설계안**
- STANDARD (월 8,500 유지): 고해상 다운로드 무제한(다운로드 권한 시스템 이미 존재) + 아카이브 전체 열람 + 광고 없는 경험(향후 광고 도입 시 차별점)
- PREMIUM (월 15,000~19,000): + 신작 48시간 조기 공개(scheduled_publish 활용) + 월 1회 에디터 큐레이션 레터 + 커뮤니티 챌린지 우선권·프리미엄 배지
- CREATOR (월 25,000, 신설 검토): + 서브미션 상세 피드백 1회/월 + 크리에이터 포트폴리오 페이지 + 캐스팅 풀 등록(4-2 연결)

**수익 감각** — 가입자 548명 중 5% 전환 = 27명 × 평균 12,000 = MRR 32만. 1년 뒤 가입자 5천 명 × 5% = MRR 300만. 구독은 복리 — 일찍 시작할수록 유리.

**실행 단계**
1. 티어 혜택 위 안대로 확정 → subscribe 페이지 카피 전면 개편 ("왜"를 첫 문단에)
2. 548명에게 재론칭 이메일 (첫 달 50% 쿠폰) — 이메일 시스템 완비
3. 다운로드 시도 시 페이월 모먼트가 최대 전환 지점 — 그 화면의 카피·디자인 집중
4. 매월 구독자 수를 growth-audit으로 추적 (이미 지표 있음)

**리스크** — 무료였던 것을 잠그면 반발 — 신규 콘텐츠부터 적용하고 기존은 유지하는 그랜드파더링.

## 2-2. 프린트/굿즈 (주문형)

**개념** — 화보를 실물로: 아트 프린트, 연간 포토북, 포스터. 주문형 인쇄(POD)로 재고·초기비용 0.

**PAP 적용** — 92편의 화보가 곧 상품 카탈로그. 크리에이터와 수익 셰어(creator_earnings 테이블 활용)하면 크리에이터가 자기 팬에게 홍보하는 유통망이 된다. **선행 조건: 크리에이터와 판매용 사용권 계약** (기존 게재 동의에 판매권은 없을 가능성 높음 — 신규 서브미션 약관에 옵션 추가 + 기존작은 개별 동의).

**가격 감각** — A3 아트 프린트 3만~6만(원가 8천~1.5만), 연간 포토북 5만~9만. 월 30장 판매 시 매출 100만·마진 60만 수준.

**실행 단계** — ① 사용권 동의 확보한 화보 10편으로 파일럿 ② POD 파트너(국내: 퍼블로그·레드프린팅 / 글로벌: Prodigi) 연동 ③ 에디토리얼 페이지에 "Print 구매" 버튼 (개발 반나절).

## 2-3. 크리에이터 유료 서비스

**개념** — 크리에이터에게 교육·피드백을 판다. 최근 서브미션 다수가 REJECTED — 거절당한 사람이 원하는 건 "왜, 어떻게 고치나"이고, 그 답을 줄 수 있는 유일한 곳이 PAP 에디터다.

**상품안**
- 서브미션 상세 피드백 리포트: 컨셉·스타일링·셀렉션·리터칭 항목별 코멘트 + 재제출 가이드 — 3만~5만원
- 에디토리얼 제작 워크숍(온라인, 월 1회): 기획→팀빌딩→촬영→서브미션 — 10만~20만원/인
- 포트폴리오 리뷰 1:1 — 15만~25만원

**⚠️ 금지선** — **게재 자체를 팔지 말 것** (pay-to-publish). 심사의 공정성이 무너지면 크리에이터 커뮤니티 전체와 매거진 권위가 붕괴한다. 파는 것은 피드백·교육이며, 유료 서비스 이용이 심사에 영향 없음을 명시.

**실행 단계** — 거절 메일에 피드백 리포트 옵션 링크 한 줄 추가 → Paddle 단건 결제 → 수요 검증 후 워크숍 확장.

## 2-4. Pull-Letter 유료화

# 3축 — 트래픽 기반

## 3-1. 어필리에이트 (인프라 이미 존재 — 최우선 심기)

**개념** — 화보 착장(Fashion by)에 구매 링크를 걸고 판매 수수료(3~15%)를 받는다. 콘텐츠와 완벽히 자연스러운 결합이라 UX 훼손이 없고, 트래픽이 커질수록 자동으로 커진다.

**PAP 적용** — affiliate_clicks 테이블 + /go/:id 리다이렉터가 **이미 코드에 존재하고 미사용**. 파이프가 깔려 있는데 수도꼭지를 안 연 상태.
- 글로벌 독자(60%+): ShopMy·LTK(패션 특화), Amazon Fashion, FARFETCH 제휴
- 국내: 무신사·W컨셉·29CM 파트너스, 쿠팡 파트너스

**수익 감각** — 현재 트래픽(월 5.1천 PV)로는 월 수만 원. 그러나 월 10만 PV + 구매 전환 1% + 객단가 15만 × 수수료 7% = 월 100만+. Pinterest 파이프라인(구매 의도 트래픽)과 시너지가 특히 큼.

**실행 단계**
1. ShopMy/LTK 크리에이터 계정 신청 (IG 37만이면 승인 무난)
2. 어드민 착장 크레딧에 "구매 링크" 필드 추가 → /go/:id 경유로 클릭 추적 (개발 반나절, 요청 시 구현)
3. 신규 에디토리얼부터 적용, 조회 상위 기존작 소급
4. 공시: "이 링크로 구매 시 PAP에 수수료가 지급됩니다" 푸터 문구

## 3-2. 디스플레이 광고 (애드센스/프로그래매틱)

현재 5.1천 PV → 월 1~3만원으로 브랜드 비용 대비 비효율 (별도 분석 완료). **월 5만 PV를 도입 트리거**로. 도입 시에도 기사 하단 1슬롯 등 프리미엄 지면 보호 + 구독자 광고 제거 혜택 연동. 5만 PV에서 월 10~25만, 20만 PV에서 40~100만 예상.

## 3-3. 유튜브/필름 수익화

패션 필름 자산 존재. 채널 구독 1천+시청 4천 시간 도달 시 광고 수익 + 브랜드 필름 커미션(1-6 스튜디오와 연결). 지금은 필름을 유튜브에 정기 업로드하는 습관부터.

# 4축 — IP·데이터·중개

## 4-1. 콘텐츠 라이선싱

**개념** — 이미 만든 화보의 2차 사용권 판매: 브랜드 자사 채널, 매장 디스플레이, 광고 소재. 한계비용 0의 순수 마진.

**가격 감각** — 사용 범위·기간별 30만~300만. 스폰서드 계약서에 "2차 사용은 별도 라이선스" 조항을 박아두는 것이 시작 (1-1과 세트).

**주의** — 크리에이터·모델 초상권 포함 여부를 계약서에 명시 — 정산 셰어 구조(creator_earnings) 활용.

## 4-2. 캐스팅/매칭 중개

**개념** — 브랜드 ↔ 크리에이티브 팀(포토그래퍼·스타일리스트·모델) 연결 수수료 10~20%. PAP의 크레딧 DB(creators 테이블 + 92편 크레딧 이력)가 그대로 검증된 포트폴리오 풀.

**수익 감각** — 촬영 1건 팀 페이 500만 기준 수수료 50만~100만. 월 2건이면 100만~200만.

**실행 단계** — 스튜디오(1-6) 문의 중 "직접 계약 원함" 수요를 매칭으로 전환 → 크리에이터 티어(2-1) 가입자를 캐스팅 풀로 → 중개 약관·수수료 규정 문서화.

## 4-3. 페퍼릿 — 별개 매거진의 독립 수익화

페퍼릿(구 PAP코리아, 14만)은 PAP과 별개 브랜드로 자체 트랙: 케이팝 팬덤 타깃 스폰서드 콘텐츠(뷰티·패션·엔터), 팬덤 커머스 제휴, 자체 미디어킷(보유). Z세대 17~24 팬덤이라는 선명한 타깃이 광고 영업에서 오히려 강점 — PAP과 패키지 판매하지 않는 것이 원칙. 상세 플레이북은 페퍼릿 편에서 별도 작성 권장.
