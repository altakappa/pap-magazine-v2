# 실시간 셀럽 속보 배포 키트 (K‑POP Rapid Distribution Kit)

> PAP / PEPPERIT 셀럽 취재 → 인스타 게시물에 **팬을 짧은 시간 안에 결집**시키기 위한 실전 키트.
> 핵심 원리: 인스타 알고리즘은 게시 후 **첫 30~60분의 참여 속도(velocity)** 를 본다.
> 이 시간에 **좋아요·저장·보내기·댓글**이 몰리면 탐색탭/해시태그 상단으로 밀려 올라간다.
> 그리고 지금 IG에서 가장 강한 신호는 **저장(save) · 보내기(send)** — K팝 팬이 원래 하는 행동이다.
>
> 계정: **PAP → @pap_magazine** · **PEPPERIT → @pepperitmag** (셀럽 데일리는 주로 PEPPERIT)

---

## 1. 30초 배포 워크플로우 (현장 → 게시)

취재/촬영 직후 **이 순서대로, 최대한 빠르게**:

1. **IG 먼저** — 대표 캐러셀(최고 컷 3~10장) 업로드. 아래 §2 IG 캡션 템플릿 사용. 셀럽·소속사·이벤트 태그 필수.
2. **X(트위터) 즉시** — IG 올린 그 순간, X에 대표컷 1장 + IG 링크 + 팬덤 해시태그. **X가 결집 엔진이다.** (§2 X 템플릿)
3. **Threads** — IG와 연동돼 몇 초면 끝. 같은 대표컷 + 짧은 코멘트 + 링크.
4. **(선택) 팬 채널 공유** — 오픈카톡/디스코드/팬카페에 IG 링크 (팀·커뮤니티 담당).

> ⏱️ 목표: **취재 종료 → 3채널 배포까지 5분 이내.** 속도가 곧 순위다.
> 미리 §2 템플릿을 메모앱/단축어에 저장해두면 붙여넣기만으로 끝난다.

---

## 2. 붙여넣기 템플릿

`{}` 부분만 채우면 된다. `{계정}` = `pap_magazine` 또는 `pepperitmag`.

### 2‑1. 인스타그램 캡션 (바이링구얼 + 저장/보내기 CTA)

```
{셀럽/그룹} — {이벤트/상황} 📸

{한 줄 코멘트, 한국어}
{one‑line comment, English}

📌 저장하고 최애 소식 놓치지 마세요 · 친구에게 보내기 ↗
📌 Save it & send to a friend who stans {셀럽}

🎞 더 많은 컷·영상은 @{계정}

—
@{셀럽공식} @{소속사공식}
#{그룹해시태그} #{멤버해시태그} #{이벤트해시태그} #{팬덤해시태그}
#kpop #케이팝 #{계정브랜드해시태그}
```

- **저장·보내기 CTA를 캡션 최상단 근처**에 둔다 (스크롤 없이 보이게).
- 첫 줄에 셀럽/이벤트 키워드 → 검색·해시태그 노출.
- 캐러셀은 "가장 강한 컷을 1번"에 (첫 장이 저장률을 좌우).

### 2‑2. X (트위터) — 결집용 (가장 중요)

```
{셀럽} {이벤트} 🔥

📸 전체 사진·영상 👉 instagram.com/{계정}

#{그룹해시태그} #{멤버해시태그} #{이벤트해시태그} #{팬덤해시태그} #{그룹영문} #kpop
```

- **이미지 1장(대표컷)을 반드시 첨부** — 이미지 트윗이 RT·클릭이 훨씬 높다.
- 셀럽 공식 X 계정 태그 or 언급(과하지 않게 1개).
- 이벤트 실시간이면 **해당 이벤트 실시간 해시태그**를 꼭 포함(팬들이 그 태그를 모니터링 중).

### 2‑3. Threads

```
{셀럽} {이벤트} 오늘의 컷 🖤
전체는 인스타 @{계정} 에서 · 저장📌 환영

#{그룹해시태그} #{팬덤해시태그} #kpop
```

## 4. 저장 · 보내기 · 속도 최적화 체크리스트

게시할 때마다 빠르게 점검:

- [ ] **첫 장(커버 컷)** 이 가장 강한 이미지인가? (저장률·정지율 결정)
- [ ] 캡션 **상단**에 "저장📌 · 보내기↗" CTA가 있는가?
- [ ] 셀럽 **공식 계정 + 소속사 + 이벤트** 태그를 했는가?
- [ ] 해시태그를 **한글 + 영문** 둘 다 넣었는가?
- [ ] 캐러셀인가? (단일보다 캐러셀이 체류·저장 유리)
- [ ] IG 올린 **직후 X·Threads**에 대표컷+링크를 뿌렸는가?
- [ ] 첫 댓글에 **핵심 정보/추가 링크**를 고정했는가? (댓글 유도 = 참여 신호)
- [ ] 스토리에도 게시물 **리포스트 + "저장하세요" 스티커**를 올렸는가?

## 5. 타이밍 가이드 (KST 기준)

- **골든타임**: 이벤트/행사 **직후 즉시**. 팬 관심이 최고조일 때 = 결집 속도 최고.
- **평상시 피크**: 평일 **오후 6~11시**, 주말 **오후~밤**. (팬 활동 집중 시간)
- **동시성**: IG → X → Threads를 **같은 5분 안에**. 채널 간 시차가 크면 결집이 분산된다.
- **연속성**: 큰 이벤트는 "속보 → 추가 컷 → 정리본" 식으로 **여러 게시물로 나눠** 참여를 이어간다.

## 6. 반드시 지킬 것 (계정 보호)

- **가짜 참여 금지** — 봇/구매 좋아요·팔로워는 계정 정지 + 진성 팬 신뢰 붕괴. 절대 사용하지 않는다.
- **결집은 "진짜 팬이 자발적으로" 하도록 유도**하는 것 — 우리가 하는 건 *빠르게, 정확한 태그로, 그들이 보는 채널에* 소식을 놓는 것까지.
- **저작권/초상권** — 취재 이미지·영상 사용 시 매체 크레딧/출처 원칙 준수.
- **공식 계정 핸들·해시태그는 사용 전 검증** (§3 주의).

## 부록: 왜 X가 핵심인가 (한 줄 요약)

K팝 소식은 **X의 리트윗**으로 가장 빨리 퍼지고, 팬들은 X에서 소식을 얻은 뒤 **IG 게시물로 이동해 저장·좋아요·보내기로 서포트**한다.
따라서 *"IG에 좋은 컷을 올리는 것"* 만으로는 부족하고, **X에서 그 IG 게시물로 팬을 빠르게 유입**시키는 것이 결집의 실제 트리거다. 이 키트의 §2‑2가 그 트리거다.
