# PAP MAGAZINE — Pinterest 구축·운영 가이드

> 2026-07-04 작성. 핀터레스트는 소셜이 아니라 **비주얼 검색엔진**이다.
> 핀 수명 6~12개월, 패션 에디토리얼에 최적. PAP의 화보 아카이브를
> 장기 검색 트래픽 자산으로 되살리는 채널.

## 웹사이트 준비 (구현 완료 ✅)

| 항목 | 상태 |
|---|---|
| Article Rich Pin OG 메타 (og:type=article, article:author, published_time, og:image 1200×800) | ✅ 기존 완비 |
| SSR 이미지 data-pin-* (역링크·설명 자동) — 히어로 + 갤러리 전 이미지 | ✅ 신규 |
| "Pinterest에 저장" 버튼 (SSR 상세 페이지, 커버 핀) | ✅ 신규 |
| 도메인 인증 메타 자리 `p:domain_verify` | ✅ 자리 준비 (계정 후 코드 교체) |

즉, 방문자가 PAP 기사·에디토리얼 이미지를 핀에 저장하면 → 자동으로 PAP 페이지로 역링크되고 → 룩·크레딧이 설명으로 채워져 핀터레스트 검색에 노출된다. 콘텐츠가 핀터레스트로 유입되는 플라이휠.

## 도메니코가 할 일 (계정 필요 — 순서대로)

### 1. 비즈니스 계정 생성 (5분)
- pinterest.com → 가입 → **비즈니스 계정으로 전환** (또는 business.pinterest.com에서 신규)
- 프로필: 이름 "PAP Magazine", 사용자명 `@papmagazine`(가능하면), 소개에 키워드
  - 예: `Global fashion editorial magazine — 매월 20+ 화보 · Fashion · Beauty · Culture`
- 웹사이트: `www.pap-magazine.com`

### 2. 도메인 소유권 인증
- 비즈니스 허브 → 설정 → **도메인 및 계정 연결** → 웹사이트 인증
- **"HTML 태그 추가" 방식** 선택 → `<meta name="p:domain_verify" content="XXXX">` 코드 확인
- 그 **content 값을 나(Claude)에게 알려주면** → 이미 심어둔 placeholder(`REPLACE_WITH_PINTEREST_CODE`)를 교체·배포 → 핀터레스트에서 "확인" 클릭
  - (구글·네이버 인증과 완전히 동일한 흐름)

### 3. Rich Pin 활성화
- 인증 완료 후 자동으로 리치 핀이 켜지는 경우가 많음. 안 되면 Pinterest **Rich Pin Validator**에 PAP 기사 URL(예: `www.pap-magazine.com/article/<slug>`) 입력 → "Validate" → "Apply"
- 메타는 이미 완비돼 있어 즉시 통과됨

### 4. 보드 구조 (검색어 중심)
핀터레스트 트래픽의 25%가 보드에서 나온다. 보드명 = 사람들이 검색하는 키워드:
- `Fashion Editorial` / `패션 에디토리얼`
- `Beauty Looks` / `뷰티 화보`
- `Street Style` / `스트릿 패션`
- `Film & Motion`
- `Cover Stories`
- 각 보드에 핀 20~100개가 이상적. 3개월 내 업데이트된 보드가 노출 우선.

## 핀 제작 규칙

- **비율 2:3 세로 (1000×1500px)** — 가장 중요. 가로/정사각은 노출 급감.
- **제목·설명에 키워드**: 핀 설명 첫 문장에 "fashion editorial", 브랜드·아티스트명(한/영). 구글 이미지에도 색인됨.
- **핀당 링크**: 반드시 해당 PAP 기사/에디토리얼 상세 URL로 (홈 아님).
- **콘텐츠당 핀 3~5개 변형**: 같은 화보를 다른 컷·다른 텍스트 오버레이로.
- **일관된 발행**: 하루 1~5핀 꾸준히 > 몰아치기.

## PAP 아카이브 활용 (핵심 전략)

PAP은 이미 수백 개 화보를 보유 — 핀터레스트의 최대 강점은 이 아카이브의 재활용이다.
1. 조회수 상위 에디토리얼부터 각 3~5핀으로 제작
2. 각 핀 → 해당 상세 페이지 링크 (이미 SSR + Rich Pin 준비됨)
3. 계절 키워드에 맞춰 재핀 (예: 가을엔 가을 화보 보드 상단 노출)

## 웹사이트 ↔ 핀터레스트 연결 (계정 후)
- 인증 완료되면 홈 Organization 스키마 `sameAs`에 핀터레스트 URL 추가 (내가 코드로)
- 푸터 소셜 링크에 Pinterest 추가

## 정직한 기대치
핀터레스트는 **느린 시작 → 복리 성장**. 3~6개월 뒤부터 방치해도 트래픽이 누적된다. 즉각적이지 않지만 패션 매거진에겐 투자 대비 최고의 장기 채널.
